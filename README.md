# `04 / HCI + HARDWARE`

<div align="center">

## 🧤 SMARTGUARDIANS

### `A Wearable Smart Glove for Real-Time Gesture-to-Message Communication`

</div>

An HCI project combining **wearable hardware, gesture recognition, and real-time communication**.

The prototype uses **Hall-effect sensors + MPU6050 motion sensing + Arduino + LCD + buzzer** to recognize predefined gestures and communicate messages such as:

```text
CHEST HURT       →  EMERGENCY
FEEL DIZZY       →  NEED REST
I AM OKAY        →  STATUS COMMUNICATION
```

The project explores how low-cost wearable technology can provide an alternative communication mechanism in situations where conventional communication is difficult.
